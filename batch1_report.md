## Limitations (read first)
- Small sample: n = 5 papers (batches/batch1_counts_rule4.json). These counts support no rate claims about any journal, field or repository.
- Pre-registration ordering is self-attested for batch 1. The batch 1 PREREG.md and targets.json hashes were frozen locally at 2026-10-09 15:39:18 UTC (batches/batch1_prereg_hashes.txt), before any agent run (SELECTION.md section 6), but they were first published to GitHub on 2026-10-10, together with the results (CHANGELOG_METHOD.md #5e). A reader cannot verify the ordering from public timestamps. From batch 2 onward, hashes will be posted publicly before any run.
- The two agents are not independent human replications. Agents A and B are separate runs with no shared context (B never saw A's logs, diffs or outputs), but they use the same underlying model family, so they can share blind spots.
- No author was contacted. A class C means "could not be checked from the materials the article points to". It does not mean the paper is wrong, and the missing material may exist privately or elsewhere.
- Code observations: only those marked "verified finding" in batches/batch1_code_observations.csv meet the verification standard (CHANGELOG_METHOD.md #4d). The 16 marked "unverified agent observation" are agent notes that were not verified; they are not findings (batches/batch1_code_observations_counts.json).
- Hosting: the full working tree, including files not committed to the GitHub repository (batches/batch1_publish_exclusions.tsv), is a zip hosted on Google Drive, not on GitHub; its SHA-256 is in README.md, so a downloaded copy can be checked. The zip is the revision 2 snapshot; revision 3 changes are on GitHub only.
- Paper 04's supplement was read through a document viewer because the publisher blocks direct download; no hash of the supplement file itself could be recorded (papers/04_PSHE5L/DATA_STATEMENT.md).

## 02: deviation and robustness
- Deviation: exact match needs the system clock set to the authors' run date (papers/02_ELBOXX/diffs/DEVIATION_clock.md). As-is, T4 0.05589 vs 0.05441 and T5 0.04119 vs 0.03963, both within the 5% band that defines class B (PROTOCOL.md section 7; values: papers/02_ELBOXX/A/outputs/clock_comparison.json).
- The targeted correlation is a supporting exhibit, not the paper's headline claim; the paper's main contribution is a formal model and the authors call this pattern "consistent with" rather than confirmatory (papers/02_ELBOXX/HEADLINE_CHECK.md).
- Pre-registered checks (papers/02_ELBOXX/A/outputs/robustness_pathA_faketime20250506.csv): bootstrap and year-clustered OLS hold; the |z| > 3 outlier drop (123 of 3811 rows) gives r 0.011, p 0.50.
- Exploratory, NOT pre-registered (papers/02_ELBOXX/A/outputs/exploratory_outlier.json): Spearman rho 0.049 (p 0.0025); winsorized 1/99 r 0.124; log(x+1) both r 0.088; dropping |z| > 3 on secret_alliances only (66 rows, years 1882 to 1918) r 0.004 (p 0.81); on disputes only r 0.118. Exploratory reading, not a finding: a small positive rank association remains, and most of the size of r 0.163 comes from high-secrecy years 1882 to 1918.

## 05: one verified code finding and one unverified observation (papers/05_FNTC1J/SDO_FINDING.md, papers/05_FNTC1J/A/outputs/sdo_check.json)
- Verified finding (observation 05-1): MisinfoCT_HSK.r line 1035 averages SDO1 to SDO4 plus reversed copies of items 1 and 3, so items 1 and 3 cancel: the index equals 4 + (SDO2 + SDO4)/6. Shown algebraically and numerically.
- Effect on the SDO coefficient (Table A1, p. 16): authors' index OR 1.164 (CI 1.027 to 1.320, p 0.018 raw); corrected 4-item index OR 1.054 (CI 0.995 to 1.117, p 0.071). Table A1 prints no significance star for SDO (its stars use Bonferroni-adjusted p; recomputed adjusted p for the authors' index: 0.337). Headline targets barely move (T1 1.3004 to 1.3075).
- Unverified agent observation (05-2, not a finding): the hard-coded removal of row "1400" (line 1770) does not match the script's own outlier screens; removing it changes no reported value at the paper's rounding.

## Plain-language summary
Of five randomly drawn papers, two reproduced exactly from the materials the article points to (for one of them, 02, only with the computer clock set to the authors' run date; with today's clock two secondary numbers move slightly, staying within the class B band). Three could not be fully checked because files the code needs are not at any location the article points to. For one of these, 04, the data were on a public page the article does not cite, and with it the paper reproduces exactly. No paper showed a discrepancy that changes its conclusion. In 02, one pre-specified outlier check weakened a supporting correlation, which needs follow-up. In 05, a coding slip in a control index changes one secondary coefficient, not the headline result. None of this says any paper is wrong: these are statements about what the deposited materials allow an outsider to check.
