## 1. Headline results and targets

Main claim (abstract; Results, pp. 704-708): African and Africa-based authors are underrepresented among the most influential authors (top 5% by HITS authority score in an author citation network built from 923 seed articles and 903 authors); their influence rose between 2000 and 2010 and declined after; and the share of non-African and non-Africa-based authors who cite non-African, non-Africa-based authors more than expected by chance rose again by 2021. The paper reports descriptive counts and shares only; it reports no standard errors, confidence intervals or significance tests (p. 706 says the 2021 shares are "significantly lower" without a test).

## 2. Reproduction plan

Single notebook, `replication_code.ipynb`, 10 cells, run top to bottom in one kernel (cell 9 reuses `author_attributes` from cell 6). It reads only `SciSciNet_AfricanPolitics_Data.csv` (cell 2) and `SciSciNet_AfricanPolitics_CitingCited.csv` (cell 5) from the working directory, and writes `Figure_1.png`, `author_citation_network_{2021,2010,2000,1990,1980}.png`, `output_for_table_1.txt`, `output_for_table_2.txt` there.

Pipeline:
1. Cell 1 imports numpy, pandas, networkx, matplotlib. Cells 2 and 3 load Data.csv and print paper and author counts.
2. Cell 4: Figure 1.
3. Cells 5 and 6: load citations; build weighted directed author citation networks for 1956-1980, -1990, -2000, -2010, -2021 (`G_citation[year]`), only among seed authors, self-loops excluded, both cited and citing paper year <= the end year; set node attributes.
4. Cell 7: `nx.hits` authorities, Figures 2 to 6 (spring layout `seed=42`).
5. Cell 8: Table 1. Recomputes `nx.hits(G_citation[year])` per year, sorts authors by authority (`sort_values(ascending=False)`), takes the first `round(5*num_authors/100)` rows as the top 5%, and writes counts and shares to `output_for_table_1.txt`. Source of T1, T2, T3, T6.
6. Cell 9: Table 2. Rebuilds the networks including isolated seed authors, then for each citing group computes the share of authors whose out-neighbour share of non-African, non-Africa-based authors exceeds that group's share in the whole network; writes `output_for_table_2.txt`. Source of T4, T5. Cell 9 involves no randomness.

Copy `output_for_table_1.txt`, `output_for_table_2.txt`, the executed notebook and the PNGs to `outputs/`.
- Extraction: `scripts/extract_targets.py` parses the two text files with regular expressions and writes `outputs/targets_extracted.csv` (T1 to T6 plus the complete-set shares, the 2000 and 2010 comparison values needed by the criteria, and cell 3's counts parsed from the executed notebook). `scripts/build_results.py` builds `results.json` from that CSV.

- Randomness: the notebook sets no seed for the HITS step. The main run is therefore run as deposited (unseeded); differences should be at the tolerance level. To show whether the top-5% boundary is near a tie, the extraction script also writes the authority scores at ranks 40 to 50 for 2021 and ranks 18 to 26 for 2010 (computed by calling `nx.hits` on the same `G_citation` objects after the notebook run, in the agent's own script, from a pickled `G_citation` saved by an added final cell in a copy of the notebook; the added cell only saves objects and is recorded as a diff).

## 3. Robustness checks (pre-registered)

All three checks target the main result, T1 (African share of the 2021 top 5%), with T2 (Africa-based share) reported as secondary. Each check runs in the agent's own script on `G_citation[2021]` from cell 6 (pickled as above) and `df`, using the notebook's own definitions (node attributes from cell 6, `num_authors` and complete-set shares from `df2` as in cell 8). Because the paper reports no inferential statistics, "same direction and significance" is defined as: same direction = the top-5% share is lower than the complete-set share (the "<" printed in Table 1). Significance: not applicable as a criterion, because the paper reports no test. For information only, each check also reports a one-sided hypergeometric p-value, P(X <= k) for X ~ Hypergeometric(population = complete-set size, successes = complete-set African count, draws = top-set size), via `scipy.stats.hypergeom.cdf(k, M, n, N)`; this p-value does not enter `same_direction_and_significance_as_paper`, which is set from direction only, with the note "paper reports no significance test".

R_a. Different random seed. The only stochastic step for T1 is the svds start vector inside `nx.hits`. Run `nx.hits(G, nstart=dict(zip(G, np.random.default_rng(s).standard_normal(len(G)))))` on `G_citation[2021]` for s = 20261010 (primary) and for s = 1 to 20 (spread), then apply cell 8's ranking and top-5% rule exactly (`sort_values(by='Authority', ascending=False)`, `iloc[:round(5*num_authors/100)]`). Report for the primary seed: T1 share, count, complete-set share, hypergeometric p. Report for seeds 1 to 20: min and max of the T1 and T2 shares and the number of seeds whose top-5% AuthorID set differs from the main run's. Same direction = primary-seed share < complete-set share; also report how many of the 20 seeds keep the direction. (A bootstrap of seed papers is not pre-registered: it would have no defined treatment of duplicated papers in the citation network.)

R_b. Outlier exclusion on the outcome. The outcome is the authority score (continuous). On `G_citation[2021]`, compute authorities with `nstart` from `np.random.default_rng(20261010)` as in R_a; compute z = (a - mean) / SD over all network nodes (numpy, ddof = 0); drop every author with |z| > 3 from the graph (`G.remove_nodes_from`) and from `df2`; recompute `nx.hits` on the reduced graph (start vector from `np.random.default_rng(20261010)` for the reduced node list); take the top `round(5*num_authors_reduced/100)` where `num_authors_reduced = 903 minus the number dropped` (or the reproduced N minus dropped); compare the African share in that top set with the African share of the reduced complete set (`df2` first-row values, as in cell 8). Report the number dropped and how many of them are African or Africa-based. Same direction = top share < reduced complete-set share.

R_c. Alternative reasonable analysis choice: rank by weighted in-degree (citations received from other seed authors, `G_citation[2021].in_degree(weight='weight')`) instead of HITS authority. The paper describes authority as a more nuanced alternative to raw citation counts (p. 704), so raw counts are the natural alternative. Because in-degree has ties, the top set is every author whose weighted in-degree is >= the value at rank 45 (rank `round(5*num_authors/100)` after a descending sort); report the size of that set (may exceed 45), the African share in it, the complete-set share, and the hypergeometric p. Also report, as secondary, the strict first-45 set using `sort_values(kind='mergesort', ascending=False)`. Same direction = share in the ties-included top set < complete-set share.

## 4. Known risks

- Software age: networkx 2.8.8 (Nov 2022) with numpy 2.4.1, scipy 1.17.0 and pandas 3.0.0 (all Jan 2026) is the README combination, but it has not been tried here. A failure would need a version pin (allowed env fix). No Stata or proprietary dependency.
- Python 3.14.2 named in README and notebook metadata; 3.12 used. Expected to matter little for these pure-Python/NumPy computations.
- HITS randomness and the top-5% boundary: an unseeded ARPACK start vector and an unstable default sort (`sort_values` quicksort) could reorder authors whose authority scores are equal or within tolerance at rank 45 (2021) or 22 (2010). One swapped author changes T1, T2 or T3 by about 2 or 5 percentage points. This could give a target mismatch with identical code (would be B or D depending on direction). `svds(..., maxiter=100)` could also raise `ArpackNoConvergence`; if so, record verbatim (would be E unless an allowed fix exists).
- Compute: small data (1293 author-paper rows, 24,106 citation rows), but cells 6 and 9 loop with `iterrows` and several DataFrame filters per row, for 5 years each (about 240,000 row iterations in total). Expected minutes, not hours. Figures 2 to 6 use `spring_layout` on the full network; also minutes.
- Materials: the deposit contains both files the notebook reads (see DATA_STATEMENT.md). Appendix tables are outside the notebook and are not targets.
- Default Dataverse download returns `.tab` files with different bytes for Data (220,777 against 213,493); use `?format=original` to get the `.csv` files the notebook names.
