## 2. Why the items cancel

Algebra: SDO1_r = 12 - SDO1 and SDO3_r = 12 - SDO3 (lines 377 and 387). With all four items present the authors' index is (SDO1 + SDO2 + SDO3 + SDO4 + (12 - SDO1) + (12 - SDO3)) / 6 = (24 + SDO2 + SDO4) / 6 = 4 + (SDO2 + SDO4) / 6. SDO1 and SDO3 drop out. With na.rm = TRUE and some items missing, SDO1 and SDO1_r are missing together (same for SDO3), so the index is (12 * k13 + SDO2 + SDO4) / (2 * k13 + k24), where k13 and k24 count the present items among {SDO1, SDO3} and {SDO2, SDO4}: still no dependence on the values of SDO1 or SDO3. The intended index is (SDO1_r + SDO2 + SDO3_r + SDO4) / 4 = (24 - SDO1 - SDO3 + SDO2 + SDO4) / 4. Items 1 and 3 are the pro-equality statements (We must consider all groups..., Group equality should be our ideal), so the original index contains no information from the two reverse-keyed items and is a linear rescaling of the SDO2 + SDO4 sum with slope 1/6 and range 1 to 9 instead of 1 to 11.

Numerical evidence (item-level data, 2963 rows after the authors' cleaning, before imputation):

- SDO1 + SDO1_r = 12 in every non-missing row: True; SDO3 + SDO3_r = 12: True; each item and its reversed copy are missing together: True / True.
- On the 2506 rows with all four items, max |authors' index - (4 + (SDO2 + SDO4)/6)| = 8.9e-16 (floating point zero); over all rows the general closed form (12*k13 + SDO2 + SDO4)/(2*k13 + k24) matches with max abs diff 0.
- Perturbation test: shifting SDO1 and SDO3 by 5 points on every complete row changes the authors' index by at most 0, and the corrected index by 1.719 on average.
- Correlation of the authors' index with SDO2 + SDO4 on complete rows: 1.000.
- Example (first complete row): SDO1 = 11, SDO2 = 6, SDO3 = 11, SDO4 = 6, SDO1_r = 1, SDO3_r = 1: authors' index 6.000 = 4 + (SDO2 + SDO4)/6 = 6.000; intended 4-item index 3.500. Further rows in the JSON (`cancellation.example_rows`).
- The paper's own descriptives confirm the published analysis used the 6-column index: Table B1b (p. 22) reports SDO mean 5.53, SD 0.85, range 1 to 9; the authors' index gives mean 5.53, SD 0.86, range 1 to 9 (item stage; 0.85 SD in the 2962 model rows), while the intended 4-item mean has mean 4.39, SD 1.99, range 1 to 11. A mean of 1-to-11 items that is capped at 9 is only possible if items 1 and 3 enter as constants.

## 7. Side observation (not part of the brief)

Side finding: the id column is not unique. The imputation step (lines 1210-1218) averages mice output by id and writes it back by id, so for duplicated ids every imputed column, including observed SDO_index values, is replaced by the mean over the respondents sharing that id. 5 ids occur more than once (11 rows, all in model_CTB). In 4 of these rows the observed SDO value in the model data differs from the item-level index (max diff 0.417); excluding those rows the difference is 0. B's code review mentions duplicate ids: False. Impact not quantified here.
