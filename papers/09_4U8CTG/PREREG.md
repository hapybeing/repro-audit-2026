## 1. Headline results and targets

Main claim (abstract): two studies of Eric Zemmour voters in the 2022 French elections. (i) Observational, Study 1 (FES 2022 panel): "Zemmour voters did not experience the expected boost in SWD after their first election". Text p. 9: "Compared to the reference group, SWD is lower by 0.11 points on the SWD change scale that we normalized to run from -1 to 1"; Figure 3; Table F2 (supplement p. 39, full specification). (ii) Experimental, Study 2 (vignette experiment, Zemmour block, n = 123): "evidence of a negative affective response to the out-group (Macron) win as the driving mechanism". Text p. 14: priming Macron's potential win "negatively affects SWD change, with an effect close to -1.5 points compared to the control condition. This estimate is statistically significant at a 95% confidence level in our baseline specification"; text p. 15: an effect "of almost -0.5 points on feelings towards Macron's party. While not statistically significant at conventional statistical thresholds in this model specification". Figure 6 plots these (baseline OLS, no controls, pre-registered by the authors); the numbers are in supplement Table D3 (SWD) and Table D5 (LREM affect), Model 1.

## 3. Robustness checks (pre-registered)

All three checks target T1 (Out-group Government ATE on SWD change, Zemmour block, Model 1). Each also reports the same check for T3 (LREM) as secondary; the primary `estimate` in results.json is the T1 quantity. Analysis sample = the `zemmour` data frame exactly as 02 builds it (rows of `study2_experiment_data.csv` with non-missing `treatment` and `swd_ch`, `block == "EZ"`; 123 rows expected; for T3, `lm` drops rows with missing `affect_LREM_ch`, 120 expected). Reference category = `control`. "Same direction and significance as the paper" for T1 = estimate < 0 and the check's two-sided p < 0.05 (or 95% interval excluding 0, where stated). For T3 the paper's conclusion is "negative, not significant at 5%", so for the secondary report "same" = estimate < 0 and p >= 0.05.

R_a. Stratified case bootstrap. `set.seed(20261010)` once; B = 2000 resamples; in each, resample rows with replacement within each treatment arm (keeping each arm's size, which preserves the randomised design and avoids empty arms); refit `lm(swd_ch ~ treatment)`; store the `treatmentwin_mainstream` coefficient. Report: original-sample estimate as `estimate`; percentile 95% CI (2.5th, 97.5th) and bootstrap SE in `se_or_ci`; `p_value` = min(1, 2 * min(share of bootstrap estimates >= 0, share <= 0)). Same direction and significance = estimate < 0 and the percentile CI upper bound < 0. Secondary: same procedure, separate draw continuing the same RNG stream, for `affect_LREM_ch` on its 120-row sample.

R_b. Outlier exclusion on the outcome. The outcome `swd_ch` is continuous (range -10 to 10), so the default rule applies: within the 123-row analysis sample compute z = (swd_ch - mean) / sd (R `mean`, `sd`), drop rows with |z| > 3, refit `lm(swd_ch ~ treatment)` with classical SE, report the estimate, SE, p and the number and treatment arms of rows dropped. If no row has |z| > 3, report 0 dropped and the unchanged estimate (still counts as run). Secondary: same rule on `affect_LREM_ch` within its 120-row sample.

R_c. Alternative analysis choice: ANCOVA instead of change score. Fit `lm(swd_w2 ~ treatment + swd_w1, data = zemmour)` (post-treatment SWD regressed on treatment, controlling for wave 1 SWD; a standard, usually more efficient estimator for pre/post randomised designs), classical SE. Report the `treatmentwin_mainstream` coefficient, SE, p and N. Before fitting, record in LOG.md (diagnostic, from the agent's own script) the number of rows where `swd_ch != swd_w2 - swd_w1`; run R_c as written whatever that number is. Same direction and significance = coefficient < 0 and p < 0.05. Secondary: `lm(affect_LREM_w2 ~ treatment + affect_LREM_w1, data = zemmour)`.

No robustness checks are pre-registered for Study 1 (T5): its data are not available to the audit.
