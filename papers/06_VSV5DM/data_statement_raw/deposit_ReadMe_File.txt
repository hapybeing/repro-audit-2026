* StateLeg_COVIDFacebookActivity.Rdata: This file contains the counts of total state legislator Facebook post activity for each classification and is already merged with the demographic data necessary to conduct the multivariate analysis. This data is analyzed using the file "Multivariate Analysis.Rmd". The original raw data contains the actual text from each Facebook, however, restrictions apply to the availability of these data, which were used under license for this study.

* Multivariate Analysis.Rmd: This file produces all of the figures and main text and appendix related to the primary multivariate analyses. 

* StateLeg_WeeklyCOVIDFacebookActivity.RData: This file contains the weekly counts of total state legislator state legislator Facebook post activity for each classification and is already merged with the demographic data necessary to produce the weekly trends plots and conduct the random effects models. This data is analyzed using the file “Time-Series Analysis.Rmd”

* Main Analysis.Rmd: This file produces all of the tables and figures that appear in the time series analysis in the main text and the appendix.

*All files are automatically saved in the folders, "Total Activity Analysis_RaceAndGender", "Total Activity Analysis_RaceAndGenderAndParty_v1", and ""Total Activity Analysis_RaceAndGenderAndParty_v2". You can change these file paths to a different location or use the pre-labeled folders when running this analysis.
