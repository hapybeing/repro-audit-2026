# repro-audit-2026

A reproducibility audit of 25 randomly selected 2023 to 2026 papers whose Harvard Dataverse deposit contains R or Python code, run by **Gaurang Kumar** ([@hapybeing](https://github.com/hapybeing)).

Each paper is re-run from the authors' own materials by two independent agents (A and a blind B), with three pre-registered robustness checks and a code review, then classified A to E. Every number traces to a saved output file, and every table is generated by script.

## Status
Batch 1 of 5 (papers 01 to 05) complete, revision 2. Counts: A 2, B 0, C 3, D 0, E 0. Alternatives and reasons: `batch1_report.md`.

## Files at the top level
- `batch1_report.md`: results for papers 01 to 05
- `batch1_targets.md`: every target value vs the paper, with table and page
- `PROTOCOL.md`: pre-registered method
- `SELECTION.md`: how papers were drawn (frame, seed, screening counts, pre-registration timestamp, hashes)
- `CHANGELOG_METHOD.md`: every method change, dated, with reasons
- `repro-audit-2026_batch1_rev2.zip`: the full working tree (scripts, per-paper logs, outputs, agent runs). Paths cited in the reports, such as `papers/05_FNTC1J/A/outputs/sdo_check.json`, are inside it.

## Scope
No authors were contacted. Classes describe whether the materials reproduce the paper's numbers; they are not judgements of the research. "Code observations" are listed as verified or unverified; only verified ones appear in reports.
