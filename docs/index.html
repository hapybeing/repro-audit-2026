Reproducibility audit of 25 Harvard Dataverse papers

Each paper was re-run from the authors' deposited materials by two blind AI agent runs against pre-registered targets, then classified A to E. One dot per paper; tap a dot for details.

n = 25, one repository, mostly political science. No rates. A class C means the paper could not be fully checked from the materials as deposited, not that it is wrong.

Main counts: A 16, B 0, C 9, D 0, E 0

Classes (PROTOCOL.md section 7)

  • A (16): reproduced exactly (matches to the paper's reported rounding).
  • B (0): reproduced approximately (all headline numbers within 5% relative, same direction and same significance conclusion).
  • C (9): not reproduced, materials incomplete or unclear (missing files, code that cannot produce the reported table, undocumented steps).
  • D (0): not reproduced, discrepancy remains and affects the conclusion. Only if the discrepancy survives both A and B clean runs.
  • E (0): could not run (reason stated, e.g. exceeds compute, missing system dependency that cannot be installed).
