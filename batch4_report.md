## Limitations (read first)
- Small sample: n = 5 papers (batches/batch4_counts_rule4.json). These counts support no rate claims about any journal, field or repository.
- The two agents are not independent human replications. Agents A and B are separate runs with no shared context, but they use the same underlying model family, so they can share blind spots.
- Process notes on blinding. The agents ran at the same time in one shared workspace, and the sandbox tool printed the names of files other agents had changed after some commands, so B agents saw some A file names as change notices. On 17_T1NXVQ one glob listing by B also printed two file names under the A folder. Each B agent reports opening no A file (papers/17_T1NXVQ/B/results.json, papers/19_KH0SQ2/B/results.json, papers/18_YXC5K5/B/LOG.md).
- 17_T1NXVQ, reduced bootstrap: the paper's 120-draw percentile intervals would take about 19 CPU-hours on the audit machine and were not recomputed (batches/batch4_class_rules.json). Significance uses the pre-registered reduced bootstrap with the authors' seeds: K = 4 draws for A and K = 3 for B, set by the pre-registered timing rule from the first draw's time (papers/17_T1NXVQ/A/outputs/boot_K.json, papers/17_T1NXVQ/B/outputs/bootstrap_K.json). With so few draws the SD is itself very uncertain. The reproduced draws equal the same-seed rows of the authors' deposited bootstrap file (batch4_targets.md). Alternative class E if only the full bootstrap counts.
- 17_T1NXVQ, wall time: agent A ran R_a, R_b and R_c for the primary quantity (T1, pool_xsec) only and did not run them for the secondary pool_ldv model, to stay near the 2-hour limit after two sandbox restarts; agent B ran all three for both models (papers/17_T1NXVQ/A/results.json, papers/17_T1NXVQ/B/results.json).
- Sandbox restarts: the shared sandbox restarted four times while 17_T1NXVQ was running, at about 19:23 and 20:25 UTC during agent A's run and at about 21:12 and 22:26 UTC during agent B's run, each time removing the system R installation (papers/17_T1NXVQ/A/LOG.md, papers/17_T1NXVQ/B/LOG.md). Every reported number comes from a process that completed; interrupted steps were rerun or resumed. The other four papers finished before the first restart.
- Version substitutions: 17_T1NXVQ pins package versions, but pinned igraph 1.4.1 did not compile and pinned reticulate 1.28 cannot load under Python 3.12, so Debian igraph 2.1.4 and reticulate 1.41.0.1 were used; archived rgeos and rgdal did not build and their library() lines were removed (not on the Table 1 path); R 4.5.0 on aarch64 against the authors' R 4.2.2 (papers/17_T1NXVQ/A/results.json). 16_QZNVZ0 and 20_SINIYU record no package versions and 18_YXC5K5 and 19_KH0SQ2 pin none, so current releases were used (R 4.5.0 against the authors' R 4.3.3 for 18_YXC5K5; papers/18_YXC5K5/A/results.json).
- 19_KH0SQ2, session driver: Appendix_plus.R cannot run top to bottom as deposited (its load() line is commented out). The target lines were run through the pre-registered driver, which only adds load() of the deposited .RData file (papers/19_KH0SQ2/A/diffs/Appendix_plus_driver_load.diff). Alternative class C if that driver is not accepted as an environment fix.
- 18_YXC5K5, row order: the class uses Benchmarking_DataAnalysis.Rmd exactly as deposited. That script pairs the author benchmark with the model codings by row position although the files are in different docid orders. The pre-registered docid-paired rerun (R_c) gives lower Hamming losses (T1 0.110 against 0.182) with the same ranking and direction (batch4_targets.md). Robustness never changes the class (PROTOCOL.md section 7); the row pairing itself is verified finding 18-1 below.
- 20_SINIYU, missing module: the one deposited script that computes a paper number (codes/figure6/O_B_Ku.py, T1 and T2) stops at line 17 because the module interp_radar is not deposited or at any location the article's data statement names, and no deposited code computes Table 1 (T3 to T6). The claims that need CMA-MESO and its 3D-Var system are out of scope.
- Robustness: pre-registered checks show fragile results in two papers. In 19_KH0SQ2 the France framing coefficient (T1) keeps its sign but is not significant at 0.05 in any of the three checks; in 16_QZNVZ0 the primary coefficient stays negative under Poisson estimation but its p-value is above the paper's 0.001 level (batches/batch4_results_rule4.csv, papers/19_KH0SQ2/A/results.json, papers/16_QZNVZ0/B/results.json). Robustness never changes a class.
- Paper values for 18_YXC5K5 come from a reading of the online supplement in a document viewer during pre-registration (direct download blocked); neither agent re-opened the supplement (papers/18_YXC5K5/A/results.json).
- Absence searches can show absence only within what they searched (papers/17_T1NXVQ/ABSENCE_SEARCHES.md, papers/18_YXC5K5/ABSENCE_SEARCHES.md, papers/20_SINIYU/ABSENCE_SEARCHES.md).

## Plain-language summary
Four of the five randomly drawn papers in this batch reproduced from the deposited materials: every pre-registered number matched the paper at its printed rounding, in two blind runs that agreed with each other. The fifth could not be checked, because the one script that computes a paper number needs a code module that is not in the deposit or anywhere the article points to, and the paper's table has no code at all. Two of the four needed a judgement that could be read the other way: one paper's printed confidence intervals would need many hours of bootstrap computing, so only a few draws were run, and they match the authors' own saved draws; another paper's appendix script needs one added line to load its data. In one paper the deposited script compares each article's codes with a different article's codes; the printed numbers are what that script gives, and the paper's ranking of models holds when the rows are matched correctly, with smaller error rates. In one paper a pre-registered robustness check weakens a result: the France framing effect is no longer significant under any of the three checks. None of this says any paper is wrong: these are statements about what the deposited materials allow an outsider to check.
