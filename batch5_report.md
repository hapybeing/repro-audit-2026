## Limitations (read first)
- Small sample: n = 5 papers (batches/batch5_counts_rule4.json). These counts support no rate claims about any journal, field or repository.
- The two agents are not independent human replications. Agents A and B are separate runs with no shared context, but they use the same underlying model family, so they can share blind spots.
- Process notes on blinding. The agents ran in one shared workspace. On 22_W2TSVL a listing of the paper folder by agent B showed that a folder named A exists; B reports opening nothing in it (papers/22_W2TSVL/B/results.json). The other B agents report not opening any A folder (papers/21_LEFTNE/B/LOG.md, papers/24_U9CKK6/B/LOG.md, papers/23_FXRNBA/B/LOG.md).
- Sandbox restarts. The shared sandbox restarted at about 21:12 UTC, during agent A's package installs for 21_LEFTNE (papers/21_LEFTNE/A/LOG.md) and during agent A's full run for 23_FXRNBA, which was killed and rerun from scratch (papers/23_FXRNBA/A/LOG.md); agent B of 22_W2TSVL found R missing when it started just after (papers/22_W2TSVL/B/LOG.md).
- It restarted again at about 04:55 IST during agent A's R_a bootstrap for 24_U9CKK6, which resumed from its saved draws; A's K was set from the first refit time, measured before the restart (papers/24_U9CKK6/A/LOG.md, papers/24_U9CKK6/A/results.json). Agent B of 24_U9CKK6 and agent A of 25_914AN0 found R missing at their start and reinstalled it before running (papers/24_U9CKK6/B/LOG.md, papers/25_914AN0/A/LOG.md). Every reported number comes from a process that completed.
- Version substitutions: 25_914AN0 pins package versions. The pinned lfe 3.0-0 and data.table 1.15.4 do not compile under R 4.5, so the pre-registered fallbacks were used: lfe 3.1.1 in both runs, data.table 1.18.6.1 (A) and 1.17.0 (B); the pinned fixest 0.12.0 and lme4 1.1-35.3 were used; R 4.5.0 against the authors' R 4.4.1 (papers/25_914AN0/A/results.json, papers/25_914AN0/B/results.json, papers/25_914AN0/PREREG.md).

## Plain-language summary
Four of the five randomly drawn papers in this batch reproduced from the deposited materials: every pre-registered number matched the paper at its printed rounding, in two blind runs that agreed with each other. In the fifth, every estimate matched, but one sample size in a table is one row smaller in the paper than the deposited data and code give; under this audit's rules that counts as "code cannot produce the reported table", although no conclusion depends on it. One paper could be checked only by running the parts of its scripts that make the target tables, because an earlier part of one script uses two variables that no deposited file creates. In one paper the main result keeps its sign but loses the paper's significance level when the analysis is resampled by party, and in two others some secondary results lose significance under the pre-registered checks. Three small code issues were verified, none of which changes a target: a demographic table built from the other study's data, a table whose computed means come out empty so typed-in numbers are shown instead, and a table label that names year fixed effects for models that use a linear year term. None of this says any paper is wrong: these are statements about what the deposited materials allow an outsider to check.
